08 Docs

The rules, written down.

RuleWhat the clasp doesFixed at launch
burnEach run swaps the intake for the coin and sends it to the burn address.nothing to set
titheEach run sends the whole intake to one address.the recipient
splitEach run shares the intake across up to five wallets by fixed shares.wallets + shares
vestThe creator's intake unlocks linearly over a set period.start + length
followEach run buys another coin and burns it.the followed coin
mixCombines the legs above with fixed percentages that sum to 100.legs + shares

These are the published v0 rules. No clasp program is deployed yet.

09 Questions

Short answers.

Can the creator change the rule later?

No. The rule is written once at launch. There is no admin switch and no upgrade path for a launched clasp.

Does Clasp hold my keys?

No. You sign the launch yourself. Clasp never has custody of your wallet or your coin.

Which chain is this on?

Solana. Coins launch on pump.fun and the creator fees are assigned to the clasp.

Is anything on this page live?

Only the CA, buy link, chart link and X link, once they're filled in. Every feed, board and number is labelled DEMONSTRATION.
